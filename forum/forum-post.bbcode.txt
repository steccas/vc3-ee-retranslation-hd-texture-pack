[size=large][b][color=#c9952e]What it is[/color][/b][/size]
[list]
[*][b]Full pack:[/b] one ready-to-use pack for [b]VC3 Extra Edition (ULJM05957)[/b] patched with the English ReTranslation (v20260625). It contains efonte's pack, my additions and a cleaned [font=Courier New]textures.ini[/font]. You don't need to download efonte's pack separately.
[*][b]Add-on (optional):[/b] only the new files plus the new [font=Courier New]textures.ini[/font], for people who already have efonte's pack.
[/list]

[size=large][b][color=#c9952e]What's new compared to efonte's pack[/color][/b][/size]
[list]
[*][b]143 textures changed by the ReTranslation[/b], now upscaled: title screen, main menu, Gallian map, chapter titles, Combat Report, deployment/battle UI, boss name plates and number fonts. The patch gives them new hashes, so without this they show at native resolution.
[*][b]49 UI textures with text[/b], redone with a model that handles text better: LEVEL UP, FAILED, SUCCESS, Congratulations!, OPEN FIRE, ORDER sheets, digits, months...
[*][b]2,930 textures the original pack didn't cover[/b], upscaled with efonte's model:
[list]
[*]character portraits for events and battles;
[*]299 battle minimaps;
[*]weapons, accessories and ground;
[*]vehicles and their camo/faction palette variants.
[/list]
[*][b]Odioregistrarme's 7 hand-made HD textures from post #3[/b] are included: the Gallia and Empire flags ("HD maps of Gallia and the Empire" in his post), the turn icons and a few small UI icons. They replace the AI versions.
[*][b]Cleaned textures.ini:[/b] 591 Spanish-only entries removed, because they never trigger with the English ISO. 2 Spanish entries the English version still uses are kept.
[*][b]Lossless PNG recompression of the whole pack, efonte's files included:[/b] every PNG was recompressed with oxipng (-o 4 --strip safe, no alpha tricks). Each file was decoded before and after and checked pixel-for-pixel (RGBA): all identical, file names unchanged. The pack went from 8.37 GiB to 6.87 GiB (−18%), so it's smaller to download and store, especially on Android.
[*][b]Not included:[/b] efonte's [font=Courier New]original/[/font] native dumps. If you want them, get them from his MEGA link in post #1.
[/list]

[size=large][b][color=#c9952e]Install[/color][/b][/size]
[b]Full pack[/b]
[list=1]
[*]Join the parts (see Download above) and extract [font=Courier New]VC3_E2_EN_texture_pack_20261002.zip[/font] into [font=Courier New]PSP/TEXTURES/[/font]. You should end up with [font=Courier New]PSP/TEXTURES/ULJM05957/textures.ini[/font]. If you already have a [font=Courier New]ULJM05957[/font] folder, remove or rename it first. Don't merge the two folders.
[*]Keep the folder name [b]ULJM05957[/b]: that's the disc ID of the ReTranslation ISO (Extra Edition).
[*]In PPSSPP, turn on [b]Settings > Tools > Developer tools > Texture replacement > Replace textures[/b].
[/list]

[b]Add-on (if you already have efonte's pack)[/b]
[list=1]
[*]efonte's zip extracts to a [font=Courier New]ULJM05781[/font] folder. Put it in [font=Courier New]PSP/TEXTURES/[/font] and rename it to [b]ULJM05957[/b].
[*]Extract the add-on into [font=Courier New]PSP/TEXTURES/[/font] (the archive already contains the [font=Courier New]ULJM05957/[/font] folder). Overwrite [font=Courier New]textures.ini[/font] when asked.
[*]Optional: add Odioregistrarme's textures from post #3 (overwrite). The full pack already has them.
[/list]

Tested on PPSSPP 1.20.4 on PC (Linux) and on Android (AYN Thor).

[size=large][b][color=#c9952e]Known limits[/color][/b][/size]
[list]
[*][b]Dialogue font:[/b] it's a runtime glyph cache, so it can't be precomputed. A texture upscaling shader in PPSSPP helps there.
[*][b]Short palette fades/flashes:[/b] the game generates them at runtime, so they aren't covered.
[*][b]Untranslated Japanese text:[/b] text the ReTranslation left in Japanese stays Japanese, just sharper.
[*][b]DLC:[/b] no DLC textures.
[*][b]ReTranslation version:[/b] made for v20260625. A later version that changes textures may need an update of this pack.
[*][b]"Area 3 instead of area 4" (post #3):[/b] I can't reproduce it on ULJM05957. It may only affect the original release, ULJM05781. If you see it on Extra Edition, please post the texture name from "Save new textures".
[/list]

[size=large][b][color=#c9952e]How it was made[/color][/b][/size] [size=small](short version, for the curious)[/size]
[list]
[*]I didn't dump these by playing. I decrypted DATA.BIN (PGD > CRI CPK/CRILAYLA > GIM, plus the LZ compression inside the .PAC files), then computed PPSSPP's replacement keys offline (xxh64, ignoreAddress).
[*][b]Checking the keys:[/b]
[list]
[*]Against efonte's original dumps: 6,815 textures matched pixel-for-pixel, which is 99.6% of the ones that could be checked.
[*]Against my own in-game dumps on the English ISO: 25/25.
[/list]
[*][b]Main upscale:[/b] [font=Courier New]4x_fatal_Anime_500000_G_4x_FatalPixels_340000_G_interp_075[/font], efonte's exact model, rebuilt from the two parent models. On 150 sample textures it reproduces his output exactly.
[*][b]Text/UI[/b] (the 143 + 49 textures above): [font=Courier New]4x_foolhardy_Remacri[/font].
[*][b]Mapping check:[/b] I compared every entry of the pack with the decoded game data (all 711 map/minimap entries included). I found no wrong mappings and no key collisions on ULJM05957.
[/list]
